# R6.0 Vertical — Evidence (2026-10-10)

Environment for everything marked PASS: **local-node** — Node 22 (`node:sqlite` as the D1 stand-in), file/memory object store as the R2 stand-in, Playwright Chromium 141 as the validator, **stub model provider** (returns reference Vistas; no paid calls). Nothing below was executed against a deployed Cloudflare service or a real model; those rows say BLOCKED.

Build environment limits (why some rows are BLOCKED): the registry hosts (npm, PyPI, CDNs), Cloudflare docs, and openrouter.ai were refused by the egress policy; no Docker, no `wrangler`, no Cloudflare/Google/OpenRouter credentials. Dependencies were linked from a pre-installed tool tree (`scripts/offline-install.mjs`); React/React DOM type packages came from a sparse checkout of DefinitelyTyped.

## Commands

```
node scripts/offline-install.mjs                 # or pnpm install where the registry is reachable
pnpm -C packages/contracts verify                # typecheck + 14 tests + schema export
pnpm -C services/core typecheck && pnpm -C services/core test     # 50 tests (domain, execution, runtime, http)
pnpm -C apps/web typecheck && pnpm -C apps/web test && pnpm -C apps/web build
node e2e/vertical.mjs                            # 38 browser checks, 3 accounts, artifacts in e2e/artifacts/
```
